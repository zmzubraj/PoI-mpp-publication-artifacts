# Proposed MPP Publication Gates

These are engineering targets for the prototype, not claims from the paper.

- Reproducible end-to-end run from task creation to matured receipt.
- At least 2,000 objective and 500 grounded task receipts across honest/adversarial runs.
- Clear single-pass cost curve against two-run baseline.
- Tamper-detection curve over at least 4 audit sampling settings.
- Grounded semantic FAR/FRR/ABSTAIN with confidence intervals.
- DA withholding experiment matching the expected probabilistic trend.
- Sybil/task-budget simulation showing whether identity splitting changes expected credit.
- EVM gas/state table for the normal path and dispute path.
- Next-epoch committee simulation with adversarial active-weight stress tests.
- One-command reproduction for all main tables/plots.
