## Binding requirements for the post-execution attestation

The post-execution result attestation (verified by `scripts/verify_e3_result_attestation.py`) must bind, with distinct canonical paths and the same hash set:

- model identity + commit
- configuration (confirmatory config + raw config)
- inputs (all held-out items)
- outputs (all model responses)
- trace (execution trace)
- provenance bundle (data/model/compute origin)
- run ID + timestamp
- **pre-execution-authority hashes**: the V2 manifest `self_digest` and package SHA-256

All included artifacts must use distinct canonical paths and bind the same run and pre-execution-authority hashes. Merely embedding `E3`, `C3`, or `REAL_MODEL_EXECUTION` tokens is insufficient.
